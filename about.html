Satvis: 3D satellite tracker and pass predictor

Satvis is a free, open-source satellite tracker that runs in the browser. It draws more than 12,000 satellites on a 3D globe in real time, propagating each orbit from CelesTrak element sets: Starlink, GPS and the other GNSS constellations, weather and Earth-observation craft, the ISS and other crewed stations. Set a ground station by geolocation or by picking a point on the map, and Satvis works out when each one passes over you. It can say so before the pass starts. The sky view trades the globe for a ground-level camera aimed by your phone's compass, so you look for the satellite in the sky rather than on a map of it.

What it does

  • Calculates positions and orbits for 12,000+ objects across fourteen catalogue groups
  • Predicts passes for a ground station you set by geolocation or pick on the map
  • Sends a local browser notification before a pass starts
  • Aims a ground-level sky view with the phone's compass and gyroscope
  • Draws orbit tracks, ground tracks, sensor cones and 3D models per satellite
  • Installs as a Progressive Web App and keeps working offline

Where the data comes from

Element sets come from CelesTrak as OMM JSON, the format replacing TLE for new objects. A Cloudflare Worker refreshes every group into Workers KV on a six-hourly cron, and a source that fails to fetch keeps its last known good copy instead of emptying the group. Positions are propagated with SGP4 through satellite.js. How close a prediction lands depends on how recently the element set was issued, so a satellite that has just manoeuvred will be the least accurate thing on the globe.

Built with

CesiumJS draws the globe, Vue and Nuxt UI the interface, and Workbox the offline caching. The element-set API is a Cloudflare Worker, so there is no server to run. Created by Florian Mauracher and maintained as an open-source project on github.com/Flowm/satvis under the MIT licence. An iOS app wraps the same site and schedules UserNotifications, because a browser on iOS has no local notifications of its own.
